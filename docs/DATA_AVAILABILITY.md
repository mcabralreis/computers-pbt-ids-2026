# Data Availability

## Third-party source datasets

This repository does not redistribute the original CICIoT2023 or TON_IoT datasets.

### CICIoT2023

Canonical article:

- Neto, E. C. P. et al. *CICIoT2023: A Real-Time Dataset and Benchmark for Large-Scale Attacks in IoT Environment*. Sensors 23(13), 5941 (2023). DOI: 10.3390/s23135941.

Obtain the data from the Canadian Institute for Cybersecurity's official distribution and follow the provider's current access/reuse terms.

### TON_IoT

Canonical references include:

- Alsaedi, A. et al. *TON_IoT Telemetry Dataset: A New Generation Dataset of IoT and IIoT for Data-Driven Intrusion Detection Systems*. IEEE Access 8, 165130–165150 (2020). DOI: 10.1109/ACCESS.2020.3022862.
- Moustafa, N. *A New Distributed Architecture for Evaluating AI-Based Security Systems at the Edge: Network TON_IoT Datasets*. Sustainable Cities and Society 72, 102994 (2021). DOI: 10.1016/j.scs.2021.102994.

The official UNSW distribution states that academic/public research use is free of charge and requires citation of the associated dataset publications; commercial use requires permission from the dataset author.

## Evidence generated by this study

The final PF4-A1 evidence ZIP contains committed scientific records and audit/protocol material generated by the study. It contains no redistributed source dataset archive.

## Derived outputs

The repository contains derived aggregate CSVs and figures used to support the manuscript. These do not replace the original third-party datasets and are intended for claim verification and analysis reproduction.

## Archived reproducibility record

The version-specific reproducibility archive for this study is reserved at Zenodo under DOI [10.5281/zenodo.23640914](https://doi.org/10.5281/zenodo.23640914). The source repository is available at https://github.com/mcabralreis/computers-pbt-ids-2026. The archive contains the sealed PF4-A1 evidence and derived analysis packages, but not the third-party CICIoT2023 or TON_IoT source datasets.
