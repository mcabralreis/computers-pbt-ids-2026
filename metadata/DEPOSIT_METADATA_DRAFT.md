## Description

Reproducibility package for a property-based assurance study of IoT intrusion detection using CICIoT2023 and TON_IoT. The archive preserves publication-facing code and metadata, the final PF4-A1 scientific evidence (81,000 canonical ordinals and 243,000 perturbations), read-only PF4 analysis packages, and the reviewer-hardened manuscript source. Executed assurance families are PF0–PF4. PF5 was not executed. Random Forest was not executed in PF4.
